# Журнал изменений

## 1.1.7 — 27.03.2026

### Доступы
- Экран `Доступы` сохранен в формате единого фрейма с кликабельной таблицей пользователей.
- Колонка `Сервисы` в таблице стала компактной: теперь отображается только количество назначенных сервисов.
- Добавлен поиск по сервисам (в тулбаре) для быстрого фильтра пользователей по доступу к конкретному сервису.
- В модальном окне просмотра улучшено отображение сервисов: используются цветные плашки с единым стилем.
- Лента активности в просмотре оставлена в одном столбце внутри отдельного фрейма со скроллом.

### Бэкапы
- В создание нового бэкапа добавлен scope `Доступы` (`accesses`) в интерфейсе.
- На backend добавлена поддержка scope `accesses`:
  - нормализация и валидация scope,
  - включение `app_module_state` в scoped-дамп,
  - подсчет сущности `accounts.accesses` при scoped-бэкапе `accesses`.

### Docker / локальный запуск
- Для `certgen` в `docker-compose.yaml` и `docker-compose.local.yml` добавлен retry-механизм и корректное экранирование shell-переменных.
- Устранено предупреждение compose вида `The "i" variable is not set`.

### Версия и документация
- Версия приложения обновлена до `1.1.7`.
- Обновлены версионные маркеры в README и документации (`docs/*`) до `1.1.7`.
